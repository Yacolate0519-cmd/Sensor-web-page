# TruPlasma Bipolar G2.1 數據紀錄（唯讀）

- 機台：TRUMPF TruPlasma Bipolar 4010 G2.1（PEO 電源）
- 連線：COM8（FTDI USB 轉序列）、115200 bps、8N1、位址 FFFF
- 實測日期：2026-10-22。手冊中列出的 99 個 channel 全部讀取成功（回應碼 4000）。
- 資料格式：小數是 4-byte float（little-endian），整數是 big-endian。
- 手冊：`Desktop\Bipolar4010 G2.1\Bipolar4010 G2.1\MANUAL\Manual TruPlasma Bipolar series 4000_v20.pdf`，第 67–79 頁。

## 使用方式

```
python truplasma_logger.py                         # 預設：COM8，每 1 秒一筆
python truplasma_logger.py --interval 0.5 --out run01.csv
python truplasma_logger.py --duration 600          # 600 秒後自動停止
```
按 Ctrl+C 停止。每記一筆就立刻寫進檔案，中途停止或當機也不會遺失已記錄的資料。
要換機台或增減欄位，改 `--port` / `--address` 參數，或改程式裡的 `CHANNELS` 清單。

**安全：** 程式只能送讀取命令（6112/6122/6142/6152），其他命令會被程式擋下。
通電用的 6040 和所有寫入命令（6111/6121/6141/6151）都不會送出，不會讓電源通電，也不會改到任何設定。

**注意：** 記錄期間 COM8 會被這支程式佔用。
如果原廠軟體 PVDPower 或 LabVIEW 也要用 COM8 控制電源，兩者不能同時開。

## 紀錄單位與頻率

| 項目 | 設定 |
|---|---|
| 時間戳記 | 電腦時間，ISO 格式，精度到毫秒（`timestamp`） |
| 經過時間 | 從開始記錄起算的秒數（`elapsed_s`） |
| 預設間隔 | 1 秒一筆（`--interval` 可調整） |
| 單項讀取時間 | 約 15–30 ms |
| 預設 19 項讀一輪 | 約 0.3–0.5 秒，所以最快大約 0.5 秒一筆 |
| 只讀電壓 966 | 最快大約每秒 30 筆 |
| 建議 | PEO 用 1 秒一筆。起弧階段想看細一點可以用 0.5 秒 |
| 讀取失敗時 | 該欄留空，原因寫在 `errors` 欄，程式繼續記錄 |

這些數值是電源計算好的**平均值**，不是脈衝波形。1000 Hz 單一脈衝的形狀要用示波器量。

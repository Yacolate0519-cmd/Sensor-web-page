# TruPlasma Bipolar G2.1 數據紀錄（唯讀）

- 機台：TRUMPF TruPlasma Bipolar 4010 G2.1（PEO 電源）
- 連線：COM8（FTDI USB 轉序列）、115200 bps、8N1、位址 FFFF
- 實測日期：2026-10-22。手冊中列出的 99 個 channel 全部讀取成功（回應碼 4000）。
- 資料格式：小數是 4-byte float（little-endian），整數是 big-endian。
- 手冊：`Desktop\Bipolar4010 G2.1\Bipolar4010 G2.1\MANUAL\Manual TruPlasma Bipolar series 4000_v20.pdf`，第 67–79 頁。

## 使用方式

```
python truplasma_logger.py                         # 預設：COM8，每 1 秒一筆
python truplasma_logger.py --interval 0.5 --out run01.csv
python truplasma_logger.py --duration 600          # 600 秒後自動停止
```
按 Ctrl+C 停止。每記一筆就立刻寫進檔案，中途停止或當機也不會遺失已記錄的資料。
要換機台或增減欄位，改 `--port` / `--address` 參數，或改程式裡的 `CHANNELS` 清單。

**安全：** 程式只能送讀取命令（6112/6122/6142/6152），其他命令會被程式擋下。
通電用的 6040 和所有寫入命令（6111/6121/6141/6151）都不會送出，不會讓電源通電，也不會改到任何設定。

**注意：** 記錄期間 COM8 會被這支程式佔用。
如果原廠軟體 PVDPower 或 LabVIEW 也要用 COM8 控制電源，兩者不能同時開。

## 紀錄單位與頻率

| 項目 | 設定 |
|---|---|
| 時間戳記 | 電腦時間，ISO 格式，精度到毫秒（`timestamp`） |
| 經過時間 | 從開始記錄起算的秒數（`elapsed_s`） |
| 預設間隔 | 1 秒一筆（`--interval` 可調整） |
| 單項讀取時間 | 約 15–30 ms |
| 預設 19 項讀一輪 | 約 0.3–0.5 秒，所以最快大約 0.5 秒一筆 |
| 只讀電壓 966 | 最快大約每秒 30 筆 |
| 建議 | PEO 用 1 秒一筆。起弧階段想看細一點可以用 0.5 秒 |
| 讀取失敗時 | 該欄留空，原因寫在 `errors` 欄，程式繼續記錄 |

這些數值是電源計算好的**平均值**，不是脈衝波形。1000 Hz 單一脈衝的形狀要用示波器量。

## 2026-10-22 的結論

依據：只比對手冊、`dump_20200122.xml`（`Desktop\Bipolar4010 G2.1\Bipolar4010 G2.1\`，原廠在 2020-01 匯出的設定檔）和實機讀值。這些比對都沒有對電源送任何命令。

### 機型確認
- 實機序號 204550916，跟 2020 匯出檔一致，是同一台。
- 匯出檔記錄的額定值是 Pnomin 10 kW（ch3）、Unomin 1000 V（ch2）、Inomin 25 A（ch4），跟手冊 4010 型的規格（PDF p.16）一致。**手冊規格可以套用在這台。**
- G2.1 是產品世代，4010 是功率等級（10 kW）。
- 韌體在匯出之後更新過：DSP / FPGA 從 2019121000 / 2019121001 更新到 2020021001 / 2020021002。手冊（Rev.20.2019）沒有寫適用哪一版韌體。
- 6101 回傳的型號字串是 `010100000251`。手冊沒說明它的意思，字串裡也沒有出現 4010。
- 機身銘牌（型號、序號、額定值）還沒到現場核對。

### 控制來源與紀錄器能不能同時用
- 控制來源（ch19 / 20）是 RS232，所以前面板不能開啟輸出（PDF p.62）。輸出時一定有一支程式透過 COM8，至少每 3 秒送一次 6040。
- 最可能是 LabVIEW 程式（`Desktop\power_supply\Labview\Plasma_Command_Test\`，內含 VISA 序列埠通訊），另一個可能是原廠軟體 PVDPower。
- 一次只能有一支程式打開 COM8，所以**紀錄器不能和控制程式同時開**。如果紀錄器佔住 COM8，控制程式送不出 6040，電源會在 4–5 秒內報 ActSourceFail 並關閉輸出。
- 可行的做法：
  - 讓控制程式自己記錄。6040 的回應本身就帶 Uact、Iact、Pact、電弧計數和狀態位元。
  - 或在同一支程式的 6040 之間穿插 6142 讀取。
  - 或把控制來源改成面板或類比。這要寫入 ch19 / 20，需要使用者決定。
- 手冊沒有「輸出時不能讀取」的限制，但實機只在待機時讀過。

### 雙極脈衝與頻率（手冊依據，以 PDF 頁碼為準）
- **這台可以做雙極脈衝：**
  - PDF p.34："In Bipulse, Full, Trapez and Step mode output terminals are bipolar."
  - 2020 匯出檔的 Bipulse Mode Mask（ch10033）= 255，代表 8 種模式全部開放。
- 各模式的頻率範圍：
  - Full、MonoPulse：0.001–100 kHz（p.25、p.28）
  - BiPulse、Trapez、Step：1–50 kHz（p.26、p.27、p.30）
  - 低頻模式：1–1000 Hz（p.65）
- BiPulse 的時間分配（p.26，Fig. 3.7）：
  - TA = Duty / f − Off_time
  - TB = (1 − Duty) / f − Off_time
  - Off time 範圍 0–20 %
- PEO 規劃的 1 kHz 剛好是 BiPulse 的下限，要上機確認能不能用。
- 面板選單：
  - 主選單的 Mode 可以切換模式（p.59、p.62）。
  - Frequency、Duty、Off time 在 Configuration 選單（p.65），要 OEM 存取碼 321 才能進入（p.62）。
- 可以透過 RS232 寫入的項目和安全保護：
  - 6040 送出 Uset（0–1000 V）、Iset（0–25 A）、Pset（0–10 kW），並開關輸出（p.68）。正、負脈衝沒有各自獨立的電壓設定。
  - 硬體互鎖：類比介面 pin 12，以及後面板的機械互鎖開關。
  - 寫入超出範圍的值會被拒絕（回應碼 4031 / 4032）。

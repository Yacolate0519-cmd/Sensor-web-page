# Log 樹狀圖（2026-10-30）

由 `docs/log-inventory.md` 整理而成，從大類一路展開到單一訊息、CSV 欄位和代碼。
每個節點後面的 `→` 標出它寫到哪裡。

位置代號：

| 代號 | 實際位置 |
|---|---|
| `SRV` | `logs/server_YYYYMMDD.log`（每天一檔，伺服器開著就寫） |
| `EXP` | `Sensor_Data/EXP_<id>/experiment_<id>.log`（只收實驗期間） |
| `JSON` | `Sensor_Data/EXP_<id>/experiment_<id>.json`（`errors[]`、`stop_reason`） |
| `CSV` | `Sensor_Data/EXP_<id>/` 下各 sensor 的 CSV 狀態欄 |
| `TOAST` | 網頁右上角通知（同時寫進 SRV／EXP，前綴「網頁通知 [標題]」） |
| `CARD` | 網頁上 sensor 狀態卡（原因代碼＋說明） |
| `CON` | 終端機視窗（內容同 SRV；啟動腳本的訊息只在這裡） |

凡是寫 `SRV` 的，實驗進行中也會同時寫進 `EXP`，下面不再重複標示。

# 監控頁 UI 改版規劃（2026-11-03，草案，待使用者選版本）

## 需求（使用者原話整理）
1. 左邊的列表不要一直卡在畫面上。
2. 參數視窗不要 hover 才出現；一開頁就出現。
3. 實驗進行中要在某個地方看得到這次的參數設定。

## 共同決定（三個版本都一樣）
- 移除常駐左側欄；圖表區改成滿版。
- 少用的東西（電源 COM 埠、裝置、音訊設備、Sensor 測試模式、電供設定手動模式）收進頂列「⚙ 設定」抽屜。
- 緊急停止固定在頂列右側，任何狀態都看得到。
- 欄位、驗證、檢驗流程不變，只換位置。

## 三個版本
| 版本 | 設定階段 | 實驗中參數顯示 |
|---|---|---|
| A 設定頁 → 監看頁 | 整頁就是設定表單（左右兩欄：標籤／電源參數），不顯示圖表 | 圖表上方一條參數摘要列＋計時＋結束按鈕 |
| B 開頁即彈窗 | 圖表在背景（變暗），參數視窗開頁自動置中彈出 | 右側可收合的「本次參數」窄面板 |
| C 上方參數帶 | 參數攤平成頂部橫帶，圖表在下方待命 | 橫帶收成一行摘要，可按「展開」看完整參數（實驗中唯讀） |

|---|---|---|---|

| 0.4 | 各 CSV 的狀態欄 | 每一筆數據自己的狀態（見各 sensor） | 每筆數據 |

## 1. 共用：狀態卡的原因代碼（所有 sensor 都用這套）

| 代碼 | 畫面文字 | 算失敗？ |
|---|---|---|
| `ok` | 正常 | 否 |
| `idle` | 待機 | 否 |
| `init` | 初始化中 | 否 |
| `disabled` | 未選擇／未啟用 | 否 |
| `stopped` | 已停止 | 否 |
| `driver` | 驅動／韌體問題 | 是 |
| `not_found` | 找不到裝置 | 是 |
| `busy` | Port 衝突／被佔用 | 是 |
| `no_data` | 數據收不進來 | 是 |
| `wiring` | 接線／訊號異常 | 是 |
| `out_of_range` | 超出量程 | 是 |
| `error` | 其他錯誤 | 是 |

狀態變化時自動寫的 log（每個 sensor 都一樣）：

| 事件 | 等級 | 範例 |
|---|---|---|
| 從失敗變成另一種失敗／開始失敗 | WARN 或 ERROR | `狀態變化：正常 → 數據收不進來 [no_data] 埠已開啟但溫度計無回應：…` |
| 同一原因持續失敗（節流，每 60 秒一行） | WARN | `仍在失敗 [no_data]：累計 12 次，已持續 60 秒；…` |
| 恢復正常 | INFO | `恢復正常（失敗持續 1.1 秒，期間失敗 1 次）` |
| 第一次正常 | INFO | `狀態：正常（原先為初始化中）` |
| 連續失敗達 10 次 | 狀態卡變紅「感測器斷線」＋通知 | `（已判定斷線）` |
| 停止時仍在失敗 | WARN | `停止時仍在失敗 [no_data]：持續 …秒，累計 …次` |
| 讀取時的例外（同一種只記第一次，含 traceback） | ERROR | `溫度讀取錯誤: <例外>` |
